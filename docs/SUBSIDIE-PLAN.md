# 💶 Subsidie-mini-plan Leerkwartier

> Aangelegd 2 aug 2026 op verzoek van Mark ("subsidie meer verdiepen; als abonnementen
> niet werken"). Kernvraag beantwoord: **je hebt géén bedrijf nodig.** Voor de eerste
> stap (SIDN pioniers ≤ €10k) kun je als privépersoon aanvragen; voor grotere fondsen
> heb je een **stichting** nodig (géén BV/eenmanszaak — die diskwalificeert juist).
>
> ⚠️ Subsidie = **projectgeld, geen verdienmodel.** Het vervangt abonnementen niet;
> het financiert eenmalig een project of de gratis/impact-laag. Blend is normaal:
> fondsen dragen de impact-kant, Familie/Pro dragen de duurzaamheid.

## De kernvraag: rechtsvorm

| Route | Rechtsvorm nodig | Max bedrag |
|---|---|---|
| **SIDN Fonds — pionier** | **niets** (natuurlijk persoon mag) | €10.000 |
| SIDN Fonds — project | rechtspersoon (stichting volstaat) | €125.000 |
| Oranje Fonds / Kansenfonds / Kinderpostzegels e.a. | **stichting/vereniging** (particulier + bedrijf + overheid uitgesloten) | €500–€100.000 |
| Overheid: Subsidie Kansengelijkheid Onderwijs | school + gemeente + maatschappelijke partner (consortium) | n.v.t. (€13,5 mln pot) |

**Stichting oprichten** (als/wanneer nodig): notaris + KvK + bestuur van min. 3 personen +
statuten; ~€400-600 en een dag werk. Daarna evt. **ANBI-status** aanvragen (belastingvrij +
vertrouwen bij fondsen). Dit is de échte drempel — de rest is gewoon werk.

## Trapsgewijs plan

### Fase 0 — nu (geen kosten, geen oprichting)
- **SIDN Fonds pioniersaanvraag (≤ €10.000), als privépersoon.** Beste fit: digitale
  "Tech for Good"-impact, resultaten openbaar, niet op één bedrijf gericht. Leerkwartier
  is bijna een schoolvoorbeeld. Project moet **innovatief + maatschappelijk + openbaar** zijn.
  - Concreet projectidee dat past: "gratis Doorstroomtoets-oefenen mét uitleg-op-3-niveaus
    voor minima-gezinnen + nieuwkomers (LOWAN-taalpaden)". De kansengelijkheid-hoek is sterk.
  - **Actie:** deadline/ronde checken op sidnfonds.nl/aanvragen (rondes niet publiek
    bevestigd voor 2026 — even navragen of op site kijken). Aanvraag = projectplan +
    begroting + impact.
- ⚠️ Let op SIDN-criterium "niet gericht op één bedrijf/persoon, resultaten voor iedereen
  beschikbaar." Leerkwartier is gratis en open → past, maar frame het als maatschappelijk
  project, niet als "financier mijn app".

### Fase 1 — als Fase 0 lukt óf je wilt groter: Stichting Leerkwartier
> ✅ **Mark koos dit (2 aug 2026): "als het zover komt wil ik Stichting Leerkwartier."**
> De rechtsvorm bij opschaling is dus beslist: een stichting (geen BV/eenmanszaak), mét ANBI.
- Richt **Stichting Leerkwartier** op (notaris, 3-koppig bestuur). Vraag ANBI aan.
- Dit ontsluit in één klap: SIDN-projecten (tot €125k), **Oranje Fonds** (doorlopend
  aanvragen, €500–€100k), **Kansenfonds**, **Kinderpostzegels**, **Nationaal Fonds
  Kinderhulp** — allemaal kinderarmoede/kansengelijkheid, exact jouw Leergeld-doelgroep.
- Bonus: een stichting maakt óók je outreach geloofwaardiger (partners vertrouwen een
  stichting sneller dan een privépersoon).

### Fase 2 — later: overheid via een school/gemeente
- **Subsidie Kansengelijkheid Onderwijs** (€13,5 mln): alléén via een consortium van
  school + gemeente + maatschappelijke partner. Als solo-partij kom je hier binnen als
  een school/gemeente jóu meeneemt → precies waar je warme scholen-leads (eind aug)
  goud waard worden. Niet nu forceren; opsparen tot een school "ja" zegt.

## Nog te verifiëren (niet gokken)
- ✅ **SIDN-pionier (≤€10k) = DOORLOPEND OPEN, geen deadline** (bevestigd 2 aug via
  sidnfonds.nl/aanvragen). Projecten >€10k = thema-calls 1-2×/jaar (voor later, ná stichting).
  Concept-pioniersaanvraag klaar: **docs/SIDN-PIONIERSAANVRAAG-CONCEPT.md**.
- Kansenfonds/Kinderpostzegels: actuele deadlines + of er thema-calls open staan.
- Of ANBI direct nodig is of pas later (per fonds verschillend).

## Eerlijke afweging
- **Voordeel:** je kansengelijkheid-verhaal is precies wat deze fondsen zoeken; de
  SIDN-pioniersroute is een echte instap zónder oprichting.
- **Nadeel:** eenmalig geld, competitief, en de sprong naar "echt geld" vraagt een
  stichting met bestuur + verantwoording. Dat is een keuze over hoe je Leerkwartier
  wilt runnen (non-profit-governance erbij), niet alleen een formaliteit.
- **Beslismoment voor Mark:** eerst een SIDN-pioniersaanvraag proberen (laag risico,
  geen oprichting) — pas bij succes/ambitie de stichting-stap zetten.
