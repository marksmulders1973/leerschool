# VoorleesExpress — lokale locaties (outreach-adressen)

**Datum:** 20 aug 2026
**Bron:** voorleesexpress.nl/onze-locaties/ + alle 150 individuele locatiepagina's (alle mailadressen komen letterlijk van de officiële eigen locatiepagina = ✅ eigen site; niets geconstrueerd).
**Aantal gevonden:** 150 locaties, 150 met geverifieerd e-mailadres.
**De haak:** voorlezen thuis + gratis oefenen = zelfde missie; uitleg in korte zinnen + voorleesknop.

**Let op dubbelen:** de kolom *Uitvoerende organisatie* is afgeleid uit het maildomein (de site toont alleen een logo, geen naam). Veel locaties lopen via een bibliotheek — check tegen docs/BIBLIOTHEKEN-OUTREACH.md vóór verzenden. Adressen op @voorleesexpress.nl zijn locatie-aliassen van het landelijke domein.
