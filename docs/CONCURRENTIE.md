# Concurrentie-analyse — waar staat Leerkwartier?

> **Update 2026-06-10:** verdiepende 5-agent-scan (design/funnel/ads/internationaal + kritische zelf-review) → concreet actieplan in **docs/VERBETERPLAN-2026-06.md**. Kern: marktgat bevestigd, maar de homepage-voordeur lekt (11 CTA's, geen ouder-ingang); opzeg-woede bij alle concurrenten = onze anti-claim.

> Opgesteld 2026-06-04 met live web-research (2 agents). Herzien bij elke 15-agent-audit.

## TL;DR
**Op product en prijs is Leerkwartier de sterkste in de markt. Op bereik, merk en contentdiepte staat het vrijwel nergens.** Een beter product dat bijna niemand kent. Het gevecht draait niet om features — maar om distributie, vertrouwen en de kern-content áf maken vóór een grote speler het venster sluit.

- **Productidee / USP: 8,5/10** — beste positionering in de markt.
- **Marktpositie / bereik: 2,5/10** — nieuwkomer, ~400 bezoekers, 0 betalend.

## Waar Leerkwartier echt wint (marktgaten)
1. **Gratis + interactief + diepe uitleg** — Squla/JE betaald; gratis opties oppervlakkig. Niemand bezet dit.
2. **Uitleg op 3 niveaus** — bij geen enkele concurrent gezien.
3. **Echte examenvraag mét uitleg + concept-doorlink** — Examenblad/AlleExamens geven alleen antwoorden; Examenbundel geen leerpad.
4. **Curriculum-correct + kindveilig** vs. ChatGPT dat juist op rekenen faalt.

## Twee structurele bedreigingen
1. **ChatGPT/AI gratis** = substituut voor "uitleg an sich". Verweer = betrouwbaar + examen-echt + kindveilig + concept-doorlink.
2. **Grote speler kopieert de USP mét distributie** (StudyGo/Slimleren). Voorsprong = tijdsvenster, geen vesting.

## Wat dit betekent voor focus
Niet nóg een feature — het product is al beter. Wat telt:
1. **USP wáár maken** (antwoord-leak opruimen) + **zichtbaar** (homepage-demo ✅ live 2026-06-04).
2. **Kern compleet maken** zodat de belofte de vulling dekt (Doorstroomtoets-kern 36% → 100%).
3. **Distributie + vertrouwen** — FB-reels, referral-actie, eerste echte ouder-recensies.
