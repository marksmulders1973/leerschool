📋Leerkwartier

Zet gratis een oefen-lijstje klaar voor je klas

Kies een paar onderwerpen, deel één code met je klas, en je leerlingen oefenen voor de Doorstroomtoets — met uitleg op 3 niveaus. Gratis, en je leerlingen hebben er geen account voor nodig.

📋 Maak je eerste takenlijst →

Hoe het werkt — in 3 stappen

1

Maak een takenlijst

Geef de lijst een titel ("Week 24 — spelling") en kies een paar onderwerpen uit het aanbod: rekenen, taal, begrijpend lezen, studievaardigheden.

2

Deel de code

Je krijgt een korte deelcode. Zet die in de klas-WhatsApp, Teams, Google Classroom of op het bord.

3

Leerlingen oefenen + vinken af

Ze vullen de code in op leerkwartier.app, maken de taken (met uitleg op 3 niveaus bij een fout) en vinken af. Een volle lijst geeft een leuke beloning.

Waarom leerkrachten het gebruiken

  • Gratis — voor jou én je leerlingen, geen abonnement.
  • Geen leerling-accounts — alleen een code invullen, zo gestart.
  • Uitleg op 3 niveaus — bij een fout krijgt je leerling uitleg (basis / simpeler / nog simpeler), geen kaal "fout".
  • Doorstroomtoets-gericht — oefenstof in de stijl van de toets, voor groep 6-8.
  • Zelfstandig — handig als huiswerk, voor de snelle klaar-leerling, of als oefenmoment in de klas.

Veelgestelde vragen

Is het echt gratis?

Ja. Takenlijsten maken en oefenen is gratis. Leerlingen hebben geen account nodig — ze vullen alleen de deelcode in.

Wat kunnen leerlingen oefenen?

Rekenen, taalverzorging/spelling, begrijpend lezen, woordenschat en studievaardigheden voor groep 6-8, in de stijl van de Doorstroomtoets. Bij elke fout opent uitleg op 3 niveaus.

Hoe delen leerlingen de takenlijst?

Je krijgt een korte deelcode. Zet die in de klas-WhatsApp, Teams, Google Classroom of op het bord. Leerlingen openen leerkwartier.app en vullen de code in.

Zie ik wie het af heeft?

Nu vinken leerlingen af terwijl ze de taken écht afronden (geen vals afvinken). Een leerkracht-overzicht per klas staat op de planning.
